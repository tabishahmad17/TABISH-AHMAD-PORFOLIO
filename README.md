## 🛠️ Tech Stack
This portfolio is a lightweight, high-performance static website built with:
* **HTML5**: Semantic structure and modern layouts.
* **CSS3**: Custom variables, Flexbox/Grid layouts, glassmorphism UI, and dark mode themes.
* **Vanilla JavaScript**: DOM manipulation, dynamic scrolling calculations, and HTML5 Canvas API.
* **HTML5 Canvas**: Used for the custom, smooth scroll-based background video animation.

## 🌟 Features
* **Scroll-Based Video Background**: The background video dynamically scrubs forward and backward based precisely on the user's scroll percentage.
* **Glassmorphism UI**: Beautiful semi-transparent, frosted-glass sections that allow the background video to remain visible.
* **Responsive Design**: Fully responsive CSS Grid and Flexbox structures that adapt to any screen size.
* **No Frameworks**: 100% vanilla code for blazing-fast load times and zero dependencies.
